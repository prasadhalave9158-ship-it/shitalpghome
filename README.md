# Shital PG Booking Web Project

## Structure
- index.html — main webpage
- public/
  - css/style.css — browser-ready stylesheet
  - js/app.js — JavaScript extracted from the original page
  - images/ — extracted embedded image assets
- sass/style.scss — editable Sass/SCSS source

## Run
Open `index.html` in a browser. The project keeps the original page content and functionality while separating the assets.

If you edit `sass/style.scss`, compile it to `public/css/style.css` using Sass before deploying.
